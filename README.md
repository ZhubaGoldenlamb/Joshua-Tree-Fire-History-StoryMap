# Joshua Tree Wildfire StoryMap

This project is an **ArcGIS StoryMap** designed to communicate wildfire history and vegetation context in Joshua Tree National Park through interactive maps and narrative text. The StoryMap emphasizes **temporal fire patterns**, **vegetation community context**, and the role of invasive annual grasses in fire spread.

---

## Overview

The StoryMap visualizes wildfire burn scar polygons moving through time across Joshua Tree National Park, overlaid on vegetation community data. By animating fire perimeters and placing them in ecological context, the application highlights that **Cheatgrass-dominated habitats account for a large proportion of burned areas**.

The narrative component links fire occurrence with **prior wet years**, reinforcing the grass–fire cycle observed in desert ecosystems.

---

## Interactive Web Map

At the core of the StoryMap is an interactive web map that:
- Displays wildfire perimeters by year
- Shows vegetation community types beneath burn scars
- Allows users to visually compare fire occurrence across time and space

This map supports exploration of **when and where fires occurred**, and how those patterns relate to vegetation distribution.
